# AI기반 재작업 통합 관리 대시보드

기존 요구사항 명세서에 따른 Streamlit + SQLite 기반 1차 버전입니다. AI 예측·이상탐지와 ERP 직접 연동은 포함하지 않습니다.

## 실행

이 폴더의 `대시보드 실행.cmd`를 실행하고 http://127.0.0.1:8511/rework-dashboard 에 접속합니다. 다른 프로젝트와 구분하도록 전용 포트와 경로를 사용합니다. 처음에는 관리자 이름·아이디·비밀번호를 직접 설정합니다. 이후 가입 신청은 설정 화면에서 승인합니다.

다른 PC에 설치하는 경우 Python 3.12 이상에서 `python -m pip install -r requirements.txt`를 실행한 다음 시작합니다.

## 사용 순서

로그인 아이디는 이메일입니다. 기존 계정은 로그인 화면의 `기존 아이디를 이메일로 전환`에서 기존 아이디와 비밀번호를 확인하고 이메일을 한 번 등록하세요. 기존 사용자 번호·권한·작업 이력은 유지됩니다.

`아이디 저장`을 선택하고 로그인하면 해당 브라우저에 이메일만 30일간 저장합니다. 체크를 해제하고 로그인하면 저장된 이메일을 삭제합니다. 로그인 세션은 8시간 유지되며 로그아웃하면 해제됩니다.

비밀번호 분실 시 관리자에게 본인 확인을 요청합니다. 관리자 확인 및 코드 발급에는 시간이 소요될 수 있습니다. 관리자는 `설정 → 비밀번호 재설정 코드 발급`에서 본인 확인 체크와 관리자 비밀번호 확인 후 코드를 발급해 요청자에게 직접 전달합니다. 사용자는 로그인 화면의 `비밀번호 찾기`에서 이메일·코드·새 비밀번호를 입력합니다. 코드는 30분간 한 번만 유효하며 재발급 시 이전 코드가 무효화됩니다. 비밀번호 변경 시 기존 로그인 세션이 모두 해제됩니다. 이메일 자동 발송은 사용하지 않습니다.

1. 상단에서 완제품재작업 또는 대여재작업을 선택합니다.
2. 업로드·검수에서 ERP 입고 장표 또는 해당 카테고리의 마스터를 선택합니다.
3. SITE·담당자·시리얼과 이상치 목록을 확인하고 수정합니다. 검수 완료를 체크한 뒤 마스터에 반영합니다.
4. 재고현황에서 필터를 적용하거나 입고일·공수 등을 수정합니다. 편집 내용 저장 후 대상 ID를 선택하고 완료 처리합니다.
5. 완료이력과 비용리포트에서 결과를 확인하고 엑셀을 다운로드합니다.

ERP 입고일은 업로드한 날짜를 사용합니다. 마스터 업로드는 기존 입고일·완료일·공수 등 업무 항목을 보존합니다. 동일 내용의 파일은 같은 카테고리에 다시 반영되지 않습니다. 내용을 바꾼 파일은 다른 파일로 인식하므로 기존 행을 수정하려면 재고현황을 사용하세요.

## 이관 및 원본 보존

제공 원본을 확인한 유효 데이터는 완제품 1,511건, 대여 1,570건입니다. 번호만 있는 빈 행은 각각 4,407건, 93건이며 대여 파일에는 완전 공백 1행이 추가로 있습니다. 이 빈 행들은 업무 데이터와 재고 집계에서 제외했습니다.

`python scripts/initialize_data.py`는 최초 이관용이며 재실행하면 이미 이관한 카테고리를 건너뜁니다. 원본 파일은 변경하지 않으며 보관본은 `data/raw`, DB는 `data/rework.db`, 이관 결과는 `data/migration_report.json`에 저장합니다.

장기재고 기본 기준은 카테고리별 180일입니다. 기본적으로 폐기를 포함하며 설정에서 제외 구분을 지정할 수 있습니다. 입고일 누락은 재고에는 포함하되 경과일 판정에서 제외합니다.

비용 = 투입공수(시간) × 분당임율 × 60이며 기본 분당임율은 547원입니다. 0.8시간은 26,256원입니다. 비용 엑셀은 재작업현황·대여반납 두 시트를 제공합니다. 마스터 백업은 원본 열 순서·열 이름을 유지한 xlsx입니다. 원본의 매크로·인쇄 설정·장식까지 복제하는 파일은 아닙니다.

## 운영 및 검증

기본 실행은 이 PC에서만 접속됩니다. 사내 공동 접속은 운영 PC와 접근 주소를 정한 뒤 네트워크 접근 설정이 필요합니다. 프로그램을 종료한 상태에서 `data` 폴더 전체를 복사하면 계정·설정·데이터·원본을 함께 백업할 수 있습니다.

ATEC 단독 로고 원본이 제공되지 않아 텍스트로 표시합니다. 로고를 `assets/atec_logo.png`에 두면 자동 표시합니다.

`python -m unittest discover -s tests -v`로 실제 원본 행 수·파싱·재고·비용·중복 방지·권한·화면 실행을 검증합니다. 화면 시험은 별도 임시 DB를 사용합니다.
